# ⚡ Nikola Tesla — Tribute Page

> *"The present is theirs; the future, for which I really worked, is mine."* — Nikola Tesla

A visually stunning, fully responsive tribute webpage dedicated to **Nikola Tesla**, the genius who invented the modern AC electrical system and envisioned a wireless world.

---

## 🖼️ Preview

Open `index.html` in any modern browser to view the tribute page.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🎯 **Hero Section** | Full-screen hero with animated particle canvas background and shimmering gradient text |
| 📷 **Image Section** | Royalty-free portrait from Wikimedia Commons with gradient border frame |
| 📝 **Biography** | 4 detailed paragraphs covering Tesla's full life story — written originally |
| 📅 **Interactive Timeline** | 11-event vertical timeline with animated scroll reveal and hover effects |
| 🏆 **Achievements** | 6 key achievements displayed in hover-animated cards |
| 💬 **Quote Blocks** | 2 beautifully styled quote blocks with glowing borders and 3D tilt effect |
| 🔢 **Animated Counters** | Stats (300+ patents, 86 years, 26 countries) animate on scroll |
| 🧭 **Sticky Navbar** | Appears on scroll with active section highlighting |
| ⬆️ **Back to Top** | Floating button with smooth scroll |
| ♿ **Accessibility** | Keyboard navigation, reduced-motion support, semantic HTML |

---

## 🎨 Design Highlights

- **2 Background Colors**: Deep navy (`#0f1629`) and warm cream (`#faf8f5`)
- **2 Font Styles**: Playfair Display (serif) for headings + Inter (sans-serif) for body
- **Gradient Accents**: Electric blue (`#00d4ff`) to gold (`#ffd700`)
- **Glass-morphism**: Frosted glass effect on navbar and quote blocks
- **Particle System**: Interactive canvas-based particle animation in the hero

## 🚀 How to Use

1. **Clone the repository**
   ```bash
   git clone https://github.com/<your-username>/tribute-page.git
   ```

2. **Open in browser**
   ```bash
   cd tribute-page
   open index.html
   ```
   Or simply double-click `index.html` — no build tools or server required.

3. **Deploy to GitHub Pages**
   - Push to a GitHub repository
   - Go to **Settings → Pages**
   - Set source to `main` branch, root folder
   - Your page will be live at `https://<your-username>.github.io/tribute-page/`
