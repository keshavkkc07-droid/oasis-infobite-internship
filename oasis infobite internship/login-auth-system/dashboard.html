📋 How This Auth System Works

1
Registration — Username, email, and password are validated. Password is hashed with SHA-256 before being stored in localStorage.
2
Duplicate Check — If a user with the same email already exists, registration is blocked with an error message.
3
Login — Email and password are validated. Password is hashed and compared against the stored hash. Generic error shown for wrong credentials.
4
Protected Route — This dashboard checks for a valid session on page load. Without it, you're redirected to the login page.
5
Logout — Clears the session from localStorage and redirects to the login page immediately.
